# Homepage sections (Czakon + Frankl)

## Order

1. **Hook:** what is it (category, incumbent comparison, plain statement). Headline = what · subhead = for whom/job.
2. **Hero:** real product shot; Get started + Docs; lead with how not why.
3. **Social proof:** logos, metrics if real.
4. **Differentiation:** why you over alternatives (`value-prop`).
5. **Getting started:** free trial, no credit card, quick setup.

## Frankl six check

1. Problem in customer language (before solution)
2. Villain / trend
3. Attributed proof with numbers
4. Inciting event / urgency
5. Social proof (named)
6. Low-friction try (free tier, docs, GitHub)

## MVP site

Homepage, docs, pricing, navbar, About. Add later: case studies, comparisons, blog, sandbox, enterprise.

## Hero CTA tree

```
Self-serve value possible?
├─ YES → Get started + Docs
└─ NO  → Docs / See how it works (no fake signup)
```

Transparent pricing. "Contact sales" for price kills dev trust.
