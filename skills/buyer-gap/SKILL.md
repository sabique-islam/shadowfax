# Buyer gap

Market to developers. Sell to buyers. Champion carries the case internally.

Framework: [references/champion-buyer.md](references/champion-buyer.md).

## Process

From repo root: `node scripts/run-state-check.js buyer-gap`.

Requires **ICP hypothesis** and **Evidence**.

1. Name user persona vs buyer persona (often different).
2. List triggers that open budget (incident, audit, scaling wall, compliance).
3. Draft champion enablement: one-paragraph business case dev can forward.
4. Map to `pricing` and `sales` next steps.

Run `review` on business case draft; `write` if paste-ready.

## Output

- User vs buyer (roles, incentives)
- Budget triggers
- Champion packet (paste-ready paragraph + numbers)
- Who to multithread on next deal

## Done

Two personas named. Champion packet drafted and reviewed. No fake enterprise pipeline.

## Refuse

Treating free-tier love as revenue. Selling only to champion with no budget path.
