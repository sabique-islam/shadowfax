# Know if it is working

**Net developer retention (Frankl):** of devs who first used in Month 1, how many in Month 2? Month 3? Below solid retention → stop acquisition; fix activation.

**DREAM stages:** Discovery (unique humans), Research (subs/community), Evaluation (signups), Activation (MAU/depth), Membership (active community).

**Weekend gate:** new dev to first value from docs alone, under 1 hour ideal, 1 day max.

**Attribution:** add "how did you hear about us?" free text; last-touch lies for dev tools.

**Fix order tree:** retention healthy? → channel producing retained users? → else `first-users` or `activation`.

Pair with PostHog MCP when available. Do not invent funnel steps they do not measure.
