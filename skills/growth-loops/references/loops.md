# Growth loops

Examples for dev tools:

- **Shared artifact:** public dashboard, badge, OG image, embed, status page
- **Collaboration invite:** second seat pulls teammate
- **Integration loop:** listed in partner marketplace; their users discover you
- **Content loop:** docs rank; template repo forks
- **Open source loop:** GitHub stars → contributors → issues → visibility

Pick loop where ICP already behaves (don't invent viral for infra buyers).

Requires month-2 retention healthy (`analytics`) before pouring fuel.

One loop, one metric, one quarter.
