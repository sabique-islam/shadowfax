# Growth loops

Hand-made growth graduated. Build engines, not more posts.

Framework: [references/loops.md](references/loops.md).

## Process

From repo root: `node scripts/run-state-check.js growth-loops`.

Requires **ICP hypothesis** and evidence of some retained users (**Last observation** or founder metrics).

1. Map current loop: trigger → action → reward → share/invite → new user.
2. Name what's missing (viral surface, shared artifact, invite mechanic, content SEO loop, integration marketplace).
3. Pick ONE loop to build this quarter. Define metric and kill.
4. Write experiment via `experimentation` if channel bet needed.

## Output

- Current loop diagram (ascii ok)
- Recommended loop (one)
- Build steps (3–5)
- Metric + kill
- What not to build yet

## Done

One loop chosen with metric. No "post more" as strategy.

## Refuse

Loops before retention proof. Three loops at once. Referral program before product stickiness.
