# Search recipes

Use the problem language from **Evidence**, not the product name first.

## Discord

- `site:disboard.org {problem}` / Disboard, Discord.me, Discordservers
- `{substitute} discord` / `{job-to-be-done} discord`
- GitHub Discussions and README "community" links of tools they already use

## Reddit

- `{problem} site:reddit.com`
- `subreddit:{niche} {workaround}`
- Sort by comments, not karma. A 12-comment thread beats a 2k-upvote meme.

## HN / Indie Hackers / forums

- `{problem} site:news.ycombinator.com`
- `{problem} site:indiehackers.com`
- Niche forums named in evidence (XSAU, DSP, homelab, whatever they already said)

## Slack / newsletters

- `{category} slack community`
- `{ICP role} newsletter` then search that archive for the complaint

Rank by time-to-a-conversation. Promo rules: read the sidebar. If it bans vendors, note that. Do not invent a server.
