# Value prop

**JTBD template:** When [situation], I want to [motivation], so I can [outcome].

**Test:** Would a skeptical developer repeat this to a colleague without cringing?

**Banned as load-bearing:** powerful, seamless, best-in-class, revolutionary, game-changer, cutting-edge.

**Good:** "8x faster builds, 2 hrs → 15 min, named user at Co X."

**Developer is hero:** "You ship Friday" not "Our platform accelerates delivery."

Sources: evidence.tsv, TAB pains/gains buckets, complaint quotes.
