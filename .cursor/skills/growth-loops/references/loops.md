# Design the next useful turn of the loop

A channel acquires a user; a loop explains how that user's value-producing action creates the next acquisition opportunity. A list of badges, invites, and directories is not a loop specification. A marketplace listing without repeated user-generated distribution is a channel, not inherently a loop.

## Establish the precondition

Read actual cohort behavior: who returned, to do which job, over what normal interval? Use a period appropriate to the product, not a universal month-two threshold. If retention is unknown, recommend a manual test with existing satisfied users. If people cannot reach first value, repair activation before amplifying arrivals.

## Choose the natural surface

| Loop | Sender's value | Recipient's value | Failure mode |
| --- | --- | --- | --- |
| Shared artifact | Show work or deliver a result | Read/use a useful result without a forced account | Branded output is useless to anyone else |
| Collaboration | Finish a real multi-person task | Act on the same task with minimal setup | Invitations are only marketing requests |
| Public reference/template | Publish reusable work | Complete the same job faster | Forks never lead to relevant use |
| Integration | Make a complementary workflow work | Discover the next necessary tool | A static listing is mistaken for compounding |
| Referral | Recommend after a value moment | Get a trusted introduction and useful first result | Rewards attract users who never return |

For incentive terms and economics, recommend `referrals` as a separate next move. Do not open it mid-turn or use a reward to manufacture retention.

## Map and measure one complete cycle

Document trigger → user action → useful output → exposure/invitation → recipient first value → recipient becomes a source of another cycle. Name the event, actor, denominator, and expected interval at every edge. Track unique people and deduplicate multiple exposures.

For one clearly defined referral generation, a directional reproduction estimate can be shares per eligible active user × unique qualified recipients per share × recipient activation fraction × fraction of recipients who become eligible sharers. If 20% share, multiply by 0.2; do not use an average already calculated across all users and apply the share fraction again. Alternative event definitions need their own calculation. A K below one may still provide useful incremental acquisition; K above one in a tiny selected sample does not prove sustainable virality.

Cycle time and saturation matter. A slow loop may lose momentum, and repeated shares to the same colleagues are not fresh reach. Report contribution and retained users, not just invitations.

## Manual rehearsal: importer result

Hypothetical: a team cleans an export and needs a colleague to approve the mapping. Give five retained users a manual read-only preview, redact private rows, and let recipients approve a synthetic mapping. Observe whether this actually saves work before building invitations. A recipient must not need to sign up merely to inspect the promised result.

Pilot: 10 eligible teams over two normal work cycles, with a cap on support hours. Choose success/kill thresholds from the team's economics and observed baseline. If teams do not invite because the workflow is private, stop rather than inserting share buttons everywhere. If invites happen but recipients cannot act, fix the recipient experience.

## Build brief

Specify sender value, recipient value, permissions and visibility, empty/error states, invitation decline/expiry, optional attribution, deduplication, event definitions, resource cap, and owner. No public artifact should expose private data by default. Add one surface at a time; distinguish product adoption from mere exposure.

Useful precedent: [Spotify's 2024 Wrapped announcement](https://newsroom.spotify.com/2024-12-04/wrapped-user-experience-2024/) documents personal results and native sharing. It demonstrates a mechanism, not a transferable acquisition lift. Use a meaningful customer outcome, not an imitation of its visual branding.
