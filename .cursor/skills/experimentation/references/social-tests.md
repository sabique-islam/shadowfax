# Social experiments with an interpretable result

The unit is a person, thread, post, or audience cohort. State which. Ten comments under one post do not create ten independent audience samples.

## Useful designs

| Question | Minimal design | Primary signal | Confound to name |
| --- | --- | --- | --- |
| Do useful replies reach relevant people? | A bounded set of source-qualified threads in one room | Welcomed job-specific conversations per reply | Topic, timing, and author reach vary |
| Does wit help this brand's replies? | Match similar contexts; vary useful/plain versus witty while preserving truth | Relevant conversations and negative responses | Tiny samples and nonrandom exposure |
| Will people complete a native challenge? | Manual prototype with willing existing audience | Completed useful tasks per starter | Existing fans are a selected group |
| Does a teardown create product demand? | One consented session with an artifact | Attendees reaching first value afterward | Attendance is not purchase intent |
| Does an invite prompt grow a useful workflow? | Eligible teams with comparison group where feasible | Recipient first value and return | Team-level clustering and repeated contacts |

## Experiment brief

Hypothesis: if this specific audience sees this useful artifact in this room, it will take this observable action because of this cited problem.

Specify sample size and unit; eligibility; one changed variable; baseline/comparison or reason none exists; cost/time cap; primary signal and denominator; first-value/return window; start/end; success, revise, and kill rules; owner. The existing experiment checker is a structural floor, not a statistical review.

Illustration: six manually selected replies over seven days in one permitted community, at most three hours total. Chosen success rule: two welcomed conversations about the job and one accepted trial. Kill if none discuss the job, or stop immediately if moderators object. This is a qualitative learning pilot, not an A/B result. Post-level reach differences prevent a causal humor-lift claim.

No fake personas, coordinated vote/comment manipulation, fake scarcity, or deceptive social proof. These contaminate the evidence as well as the relationship. The founder posts; the agent prepares the test and later analyzes supplied results.

## Readout

Give raw counts, eligible denominators, missing data, source/creative versions, audience differences, and whether the observation window finished. Label causal claims separately from descriptions. If a handful of posts does well, repeat with a comparable audience before increasing cost. If qualified visitors fail activation, route the learning to activation rather than generating more content.
