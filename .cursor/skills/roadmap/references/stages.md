# Stage → start here

| Where they are | Bottleneck usually | Start with |
|---|---|---|
| Pre-users, mostly assumption | Pain and ICP unproven | `talk-to-users`, then `icp` |
| Few users, fuzzy ICP | Cannot describe who says yes | `icp`, then `positioning` |
| Users, generic message | Positioning speaks to no one | `positioning`, `value-prop`, `homepage` |
| Good product, nobody arrives | No channel | `first-users`, `distribution`, `launches` |
| First 50 by hand, stalls when you stop | No loops | `growth-loops` |
| Devs love it, nobody pays | Buyer gap | `buyer-gap`, `pricing`, `sales` |
| Sign up and bounce | Activation leak | `activation`, then `analytics` |
| AI product, "just a wrapper" | Commodity model | `beyond-wrapper` |
| Flying blind | Wrong metrics | `analytics` |
| Support pile-up | Reactive, no system | `customer-support`, `inbound` |

When in doubt: `talk-to-users` or `market-research` before more drafts.
