# Core five

1. In one plain sentence, no jargon, what does it do?
2. Who exactly is it for? (role, company size, technical context) `[validated | assumption]`
3. What do they use today instead, and why you over that? `[validated | assumption]`
4. Stage and traction: how many users, do they come back?
5. Strongest asset: marquee logo, hard number, real user quote, live demand signal.

Optional later (skills ask just-in-time): villain, buyer vs user, motion, where ICP discovers tools, who it is NOT for, jobs-to-be-done.

Zero user interviews is valid. Note it. Flag `talk-to-users` as likely Now move in roadmap.
