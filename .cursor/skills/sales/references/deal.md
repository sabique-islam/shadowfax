# Founder-led sales

**Four parts of a real deal:** champion, buyer, pain with cost, trigger. Missing one → conversation not deal.

**Motion:** start engaged users; founder-not-sequence outreach; discovery 30/70 listen; demo their use case; frame value for buyer; arm champion; next step + date.

**"Think about it"** = undiagnosed blocker. Ask what they need to be sure.

**Thresholds:** first 10–20 deals yourself; multithread budget holder; no fear discounting.

Pair with `pricing` and `buyer-gap`.
