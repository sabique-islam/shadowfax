# First users

One channel deep. TAB members first. Things that do not scale.

Framework: [references/channels.md](references/channels.md).

## Process

From repo root: `node scripts/run-state-check.js first-users`.

Requires **ICP hypothesis**. Prefer **Evidence** from talk-to-users Q7 (where they discover tools).

1. Name 3 discovery places for this ICP. Pick ONE for this cycle (write **Channel bet** if empty).
2. List 20 people who publicly posted about the problem; draft 5 DMs via `outreach` pattern (or point to outreach).
3. Confirm weekend test / activation gate. If fail, route `activation` first.
4. One deep launch (`launches`) beats ten shallow posts.

## Output

- One channel thesis (why this room)
- 20-name list or honest "could not find"
- 5 outreach drafts or next step to run `outreach`
- Kill criteria for this channel attempt

## Done

One channel chosen with evidence. Activation gate checked. No paid ads pre-PMF unless founder insists with eyes open.

## Refuse

Spray all channels. Discord at 5 users. Community before traction. Acquisition over leaky bucket.
