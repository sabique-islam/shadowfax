# Beyond the wrapper

Defensible wedges when the model is commodity:

- **Proprietary data** or feedback loop competitors cannot copy quickly
- **Workflow embedding** (where work already happens)
- **Integrations** and system of record
- **Eval / reliability** for production (not demo magic)
- **Domain depth** (vertical compliance, terminology, benchmarks)
- **Distribution** (community, OSS, marketplace)
- **Compliance / hosting** (enterprise requirements)

**Swap test:** change the LLM API; what still wins?

Lead with wedge in positioning. Model is implementation detail unless you are the model company.
