# Beyond wrapper

Commodity model, defensible wedge elsewhere.

Framework: [references/wedges.md](references/wedges.md).

## Process

From repo root: `node scripts/run-state-check.js beyond-wrapper`.

Requires **Product truth** and **Evidence**.

1. Name what is NOT the model (data, workflow, integration, eval, domain, distribution, compliance).
2. Test: if model API swapped tomorrow, what still wins?
3. Draft positioning lead that leads with wedge, not "AI-powered."
4. Run `review` and update **Positioning bet** if founder asked.

Skip this skill if not an AI product.

## Output

- Wrapper test answer (what survives model swap)
- Wedge statement (one sentence)
- Refuse-to-say list (generic AI claims)
- Proof from product/evidence

## Done

Wedge is specific and provable. Generic "AI assistant" claims refused.

## Refuse

Competing on model brand. Feature parity with ChatGPT UI. Positioning that dies if GPT-5 launches.
