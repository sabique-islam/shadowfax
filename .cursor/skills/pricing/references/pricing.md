# Pricing framework

## Order

1. Value metric (charge per what grows with value)
2. Packaging (free line, paid triggers, enterprise)
3. Number

## Value metric tree

```
Value from more PEOPLE (collaboration)?
├─ YES → per-seat (watch seat-sharing)
└─ NO  → usage-based with floor + cap (predictability)
```

## Packaging (OSS/PLG)

- **Free:** core for solo/small; distribution not charity
- **Paid:** team, scale, SSO, audit, compliance, support/SLA
- **Enterprise:** contact when procurement/security enters

Upgrade at earned value: third teammate, 10k events, SSO need. Not countdown timers.

## Finding the number

1. "Can we pay for X?" emails (strongest)
2. Value anchor vs substitute cost
3. Competitor anchor
4. Van Westendorp range from interviews

Thresholds: some price pushback is healthy; ~10x value vs price; 2–5% free→paid normal; three tiers max self-serve; annual ≈ two months free.

## Ready to price?

Weak week-2 retention → fix activation first. Exception: buyers already asking to pay.
