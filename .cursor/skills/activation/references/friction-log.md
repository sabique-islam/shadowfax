# Activation thresholds

**Weekend test (Frankl):** motivated dev gets real value over a weekend, docs + SO only, no call.

**Time to first value (Czakon):** Hello World in minutes; meaningful win same session; target under 1 hour ideal, 1 day max.

**Hero moment:** "Look what I did" not "Look what our platform does."

## Friction log

1. Pick one core journey to first win.
2. Walk as stranger; no insider shortcuts.
3. Log per step: question, frustration, barrier.
4. Fix top 3 barriers first.
5. Metric each core moment.

## Removes friction

Free tier, no CC, copy-paste example, 5-minute path, realistic sandbox data.

## Adds friction

Signup wall before win, expert-only docs, architecture tour first run.

## Decision tree

```
Real win alone in one sitting?
├─ NO  → highest leverage work; friction log
└─ YES → week-2 return?
         ├─ NO  → wrong aha or no stickiness
         └─ YES → scale acquisition (`first-users`, `distribution`)
```
